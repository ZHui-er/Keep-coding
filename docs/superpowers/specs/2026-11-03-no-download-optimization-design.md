# 无新增下载条件下的 BLE Health MVP 优化设计

## 背景与约束

当前 Android MVP 已实现全 Mock 的设备发现、连接、设备信息、健康数据同步、Room 持久化和三页 UI，但尚未完成真实 Android 编译验证。本轮优化不得安装 Android SDK、下载新依赖或修改现有依赖版本，只使用仓库中已有的 Kotlin、Compose、Room 和测试依赖。

目标是在不扩大产品范围的前提下，提高演示稳定性、异常链路真实性、反馈准确性和代码可维护性。

## 本轮范围

### 1. 持久化错误处理

- 在 `MockHealthRepository` 的 DAO 写入边界捕获实际存储异常并转换为 `SyncResult.Failure`。
- 必须重新抛出 `CancellationException`，避免把用户取消或页面销毁误报为存储失败。
- ViewModel 增加最后一道异常保护，确保未知异常不会让 `SyncState` 永久停留在 `Syncing`。
- Room 历史 Flow 保持现有结构；数据库读取异常的完整恢复界面不纳入本轮，因为无法在不扩大状态模型的情况下可靠模拟。

### 2. 重复数据语义

- 检查 `HealthRecordDao.insert()` 的返回值。
- 返回 `-1L` 时将结果标记为重复数据，而不是“保存成功”。
- 扩展同步结果，使 UI 能显示“重复记录已忽略，历史未新增”。
- 重复数据不覆盖已有记录，也不改变历史数量。

### 3. 新增确定性异常场景

在现有七个场景基础上增加三个不依赖系统蓝牙的 Mock 场景：

- 扫描超时：扫描延迟后进入失败状态，提示重新扫描。
- 连接超时：连接延迟后进入失败状态，提示重试。
- 非法健康数据：生成全部越界指标，校验后拒绝保存并显示明确原因。

“意外断线”暂不新增独立自动定时器，以免引入不可控时序；现有手动断开继续用于演示断开后的 UI 状态。

### 4. UI 信息层级优化

保留现有 Material 3 和三页导航，不引入图标库或其他依赖。

- 首页：明确区分设备状态、最新健康数据、同步结果和主操作。
- 设备页：突出扫描状态、已连接设备和重试操作。
- 历史页：保留完整/部分标识，并改善四项指标的可读性。
- 顶部持续显示“Mock 数据 · 非真实健康测量”。
- 场景菜单继续作为全局入口，不增加独立设置页。

UI 以已确认的 Codex 内嵌预览为视觉方向，但只使用现有 Compose 组件实现，不追求像素级复刻。

### 5. 文件拆分

将接近 500 行的 `BleHealthApp.kt` 拆分为：

- `BleHealthApp.kt`：应用壳、顶部场景菜单和底部导航。
- `HomeScreen.kt`：设备摘要、健康指标和同步操作。
- `DeviceScreen.kt`：扫描、连接和设备信息。
- `HistoryScreen.kt`：历史列表和空状态。
- `UiComponents.kt`：指标卡、提示面板、日期与睡眠格式化。

ViewModel、Repository 和数据模型保持现有边界，不进行无关重构。

## 数据流

```text
用户操作
  → AppViewModel
  → DeviceRepository / HealthRepository
  → Mock 场景与数据校验
  → Room DAO
  → SyncResult（保存、重复、部分或失败）
  → SyncState
  → Compose UI
```

Repository 对可预期结果负责，ViewModel 对未预期异常提供兜底，UI 只展示状态并提供重试入口。

## 错误处理规则

- 取消操作：静默取消，不显示错误，不写入数据。
- 扫描或连接超时：进入可重试失败状态。
- 同步失败：保留上一次有效数据，不新增历史。
- 部分数据：保存有效字段并明确标记部分成功。
- 全部非法：拒绝保存并显示“所有健康指标均无效”。
- 重复数据：不新增历史，显示“重复记录已忽略”。
- 实际 DAO 异常：显示“保存失败，请重试”，同步状态不得卡住。

## 测试与验证

不下载 Android SDK，因此本轮不能声称 APK 构建通过。执行以下本地验证：

- Gradle Wrapper `--version` 自检，不触发依赖下载。
- XML 解析检查。
- Git `diff --check`。
- 搜索占位符和意外真实 BLE API。
- 添加或更新纯逻辑单元测试源码：指标校验、重复结果和异常映射。
- 人工检查十个场景对应的状态转换与 UI 文案。

完整的 `testDebugUnitTest` 和 `assembleDebug` 留给已配置 Android SDK 35 与 JDK 17 的环境执行。

## 不在本轮范围

- 真实 BLE、GATT、权限和系统蓝牙状态。
- 新增或升级 Gradle、Compose、Room 等依赖。
- CI、APK 构建或签名。
- 后台同步、自动重连、复杂动画、图表和云端能力。
- Room migration 和数据库读取故障恢复。

## 完成标准

- 实际 DAO 写入异常不会导致界面永久显示同步中。
- 重复记录不会被报告为新增保存成功。
- 扫描超时、连接超时和非法数据可确定性触发并重试。
- 首页、设备和历史 UI 拆分为独立文件，功能保持一致。
- 未增加任何依赖或执行下载。
- 静态检查通过，提交推送到 `main`，并在交付说明中明确未进行 Android 编译。
